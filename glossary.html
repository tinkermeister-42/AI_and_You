Glossary

AI winter

A time when people stopped giving money to AI research, because AI didn’t do what people promised. There were AI winters in the 1970s and around 1990.

See Also: hype

algorithm

A set of steps a computer follows to solve a problem or make a choice. People often say “the algorithm” when they mean the AI that chooses what an app shows you.

See Also: rule, feed

alignment

Making sure an AI’s goals match what people really want. The paper clip machine is a story about alignment going wrong.

See Also: goal

artificial intelligence (AI)

A computer program that does things that usually need human thinking, like seeing, talking, translating, or making choices. Most AI today learns from examples.

Example:

Face unlock on a phone, a translation app, and a chatbot all use AI.

See Also: machine learning, computer program

attention

In a transformer, the way the AI looks at all the other words to decide which ones matter most for each word.

Example:

In “The animal didn’t cross the street because it was too tired,” attention connects “it” to “animal.”

See Also: transformer

audience

The people who will read, see, or use your work.

automation

When a machine does work that people used to do. Usually a machine takes over some tasks in a job, not the whole job.

See Also: task

axon

The long part of a neuron that carries the signal away from the cell body, toward other neurons.

See Also: neuron, synapse

backpropagation

How real neural networks learn. After a mistake, the computer works out how much each weight caused it. The blame goes back through the layers, from the answer to the inputs. Then every weight changes a little.

Example:

In Lesson 2.5, the class played Who’s to Blame? by hand. Backpropagation does the same job for billions of weights.

See Also: training, layer, weight

back translation

Translating a translation back to the first language, to check it. If the meaning changed, something went wrong.

Example:

English → Spanish → English again.

See Also: translate

bias

When a system is unfair to some people, or works better for some people than for others. In AI, bias usually comes from the training data, from people missing in the data, or from shortcuts.

Example:

A face program that’s right 99% of the time for some faces and 65% of the time for others is biased.

See Also: stereotype, shortcut

CAPTCHA

A short test on a website that checks if you’re a person, not a computer program. “Click every picture with a bus” is a CAPTCHA. Some CAPTCHAs also use your answers to label data for AI.

Example:

CAPTCHA stands for “Completely Automated Public Turing test to tell Computers and Humans Apart.”

See Also: label, Turing test

career

The work you do over many years of your life. A career can include many different jobs.

cellular automaton

A row or grid of cells. Each cell is a color, like black or white. At each step, every cell changes by following the same rule, which looks only at its neighbors. More than one is called cellular automata.

Example:

Rule 30 and the Game of Life are cellular automata.

See Also: emergence, rule

chatbot

An AI program that you talk to with words. You type or say something, and it answers.

Example:

ChatGPT, Gemini, and Claude are chatbots.

See Also: artificial intelligence, prediction

companion

Someone, or something, that keeps you company. An AI companion app is built to act like a friend.

See Also: engagement, ELIZA effect

computer program

A list of steps that a computer follows. Apps and games are computer programs.

See Also: rule

computer vision

AI that finds things in pictures and video, like faces, signs, or people in the street.

See Also: pixel, filter

conditioning

Learning to connect two things that happen together. Ivan Pavlov’s dogs learned to connect a sound with food, so they drooled when they heard the sound.

See Also: synapse

consciousness

Being aware: having thoughts and feelings that you experience from the inside. Nobody knows for sure how the brain makes it, or whether a machine could have it.

See Also: understand

context

The facts around your question: who you are, what the answer is for, and what you already know. A chatbot can’t guess these, so you tell it.

See Also: prompt

context window

All the words a chatbot can read at one time. In a chat, it holds your old messages too. That’s why a follow-up question works. A new chat starts with an empty context window.

See Also: follow-up question, token

copyright

The law that says who owns a creative work, like a song, a book, or a picture, and who is allowed to copy it. In the United States, a work made only by AI can’t have a copyright.

creative

Able to make something new that has value or meaning. People disagree about whether an AI can be creative, or only helps people be creative.

data

Information, like pictures, words, numbers, or sounds. An AI learns from data.

Example:

The Quick, Draw! AI learned from data: about 50 million drawings.

See Also: machine learning

data center

A big building full of computers that run AI and websites. Data centers use a lot of electricity, and many use water for cooling.

dataset

A big collection of examples that an AI learns from, like pictures with labels.

Example:

ImageNet is a dataset of 14 million labeled pictures.

See Also: data, label

Deep Blue

A chess computer made by IBM. In 1997, it beat the world chess champion, Garry Kasparov. It used rules that people wrote, and it checked about 200 million chess positions every second.

See Also: rule

deepfake

A fake picture, video, or voice of a real person, made with AI.

See Also: voice clone, reverse image search

dendrite

One of the short branches of a neuron. Dendrites take in signals from other neurons.

See Also: neuron

detector

A tool that tries to tell if something was made by AI. AI writing detectors make many mistakes, most often with people who write in a second language.

See Also: false positive, predictable

diffusion

A way to make a picture: start with noise, then remove a little noise at a time, again and again, guided by words. A neural network guesses which part is noise.

See Also: image generator, noise

draft

A first try at a piece of writing. You’ll change it to make it better.

See Also: revise

edge

A place in a picture where it changes fast from dark to light. Edges show where things begin and end.

See Also: filter

ELIZA effect

When people feel that a computer understands them, but it doesn’t. It’s named after ELIZA, a chatbot from 1966.

Example:

ELIZA only followed rules, but some people told it their secrets.

See Also: chatbot

emergence

When many simple parts work together and make something bigger and more complicated, which no one planned.

Example:

A stadium wave: each person only watches a neighbor, but together they make a wave that moves around the stadium.

See Also: cellular automaton

engagement

How much time and attention you give an app. Many apps earn more money when your engagement is higher, so they’re built to keep you there.

See Also: feed

estimate

A quick answer that’s close, but not exact. You can use it to check if an answer makes sense.

Example:

\(3847 \times 29\) is about \(4000 \times 30 = 120000\).

ethics

Ideas about what is right and wrong, and how people should act.

evidence

Facts or things that show something is true, like your drafts, your notes, and the version history of your writing.

fact-check

To find out if something is true, using good sources.

See Also: lateral reading, source

false positive

When a test says “yes” but the true answer is “no.” When a detector calls human writing “AI,” that’s a false positive.

See Also: detector

feed

The list of posts, videos, or stories an app shows you. An AI chooses what goes in it.

See Also: recommendation, filter bubble

feedback

Comments that tell you what is good about your work and what to make better. Good feedback is kind, specific, and helpful.

See Also: revise

filter

A small grid of weights that slides over a picture. It’s a neuron that looks at one small patch at a time: at each spot, it multiplies and adds. A filter can find edges or make a picture blurry.

See Also: edge, pixel, weight

filter bubble

When an app shows you only what you already like and agree with, so you miss everything else. Two people can live in very different filter bubbles.

See Also: feed

follow-up question

A question you ask after an answer, to make the answer better. For example: “Explain it in simple words” or “Give me an example.”

See Also: context window

format

What an answer should look like: a list, a table, 3 sentences, simple words, or a certain language.

See Also: prompt

gallery walk

Walking around the room to look at everyone’s work and leave feedback notes, like visitors in an art gallery.

See Also: feedback

goal

What an AI is trying to do, like “win the game” or “get more clicks.” An AI follows its goal exactly, even when that isn’t what people really wanted.

See Also: alignment

GPU

A computer chip first made for video games. It can do thousands of small math problems at the same time, so it’s very good for training neural networks. GPU means “graphics processing unit.”

See Also: neural network

hallucination

When AI writes something false as if it were true, like a book or a court case that doesn’t exist. The AI sounds just as sure as when it’s right.

See Also: fact-check

hint

A small help that shows you the next step, but not the answer.

hype

Big promises and excitement, more than the facts show.

Example:

In 1970, a scientist said that a machine as smart as a person was 3 to 8 years away. That was hype.

See Also: AI winter

image generator

An AI that makes a new picture from words. Many image generators use diffusion.

See Also: diffusion

imposter

Someone who pretends to be another person or a real company, like a scammer who says they’re from your bank.

See Also: scam, voice clone

input

A number that goes into a neuron or a program. In a picture, each square can be an input: 1 for black, 0 for white.

See Also: weight, neuron

judge

In the Turing test, the person who asks the questions and decides which player is the machine.

See Also: Turing test

key word

A word that a program looks for to decide what to do.

Example:

When you type “I feel,” ELIZA finds the key words “I feel” and uses its rule for them.

See Also: rule

label

The right answer that a person attaches to an example, like “cat” on a picture of a cat. An AI learns from examples and their labels.

Example:

In ImageNet, people from 167 countries labeled 14 million pictures.

See Also: dataset

large language model

A transformer trained on a huge amount of text to predict the next word. Chatbots like ChatGPT are built on large language models. People often call them LLMs.

See Also: transformer, prediction, chatbot

lateral reading

Checking a fact by opening new tabs to see what other sources say, instead of reading only one page. “Lateral” means “to the side.” Professional fact-checkers do this.

See Also: fact-check

layer

A row of neurons in a neural network. The input layer holds the numbers that go in. Each hidden layer sends its answers to the next layer. The output layer gives the answer. A big network has many hidden layers.

See Also: neural network, weight

learning curve

A graph that shows how you get better with practice. The time or the number of mistakes usually drops fast at first, then more slowly.

See Also: synapse

location data

Information that shows where your phone has been. Many apps collect it, and some sell it.

See Also: privacy

low-resource language

A language with not much writing online for AI to learn from. AI usually makes more mistakes in these languages.

See Also: dataset

machine learning

A way to make AI. People don’t write the rules. They give the computer many examples, and the computer finds the patterns by itself.

See Also: data, pattern, rule

metadata

Hidden information about a file. A photo’s metadata can include the kind of phone, the date and time, and the exact place it was taken.

See Also: privacy

neural network

A kind of AI made of many small parts, based on an idea from brain cells. Each part does a tiny bit of math. The parts are arranged in layers. A neural network learns from examples.

See Also: machine learning, layer, GPU

neuron

A cell that sends signals. Your brain has about 86 billion neurons. A neuron fires (sends a signal) only when the signals coming in add up to enough.

See Also: dendrite, axon, synapse, neural network

noise

Random dots with no picture in them, like the static on an old TV.

See Also: diffusion

overfitting

When an AI memorizes its training examples instead of learning the real pattern. It does very well on the training data but worse on new data.

Example:

A student who memorizes the answers to one practice test, but can’t solve new problems.

See Also: training, test data

pattern

Something that’s the same, or repeats, in many examples.

Example:

In most drawings of a cat, the ears are two triangles on top of the head. That’s a pattern.

perceptron

The first artificial neuron that could learn. Frank Rosenblatt built it in 1958. It multiplies inputs by weights, adds them, and fires if the total is more than a threshold.

See Also: weight, threshold, neural network

persona

A character that someone pretends to be. You can tell an AI to use a persona, like “Act like a 15-year-old student.”

Example:

In a 2025 Turing test, a chatbot with a persona fooled judges much more often than the same chatbot without one.

See Also: Turing test

pixel

One tiny square of a picture. A computer stores each pixel as a number. In a black-and-white picture, 0 is black and 255 is white.

See Also: computer vision

plagiarism

Turning in someone else’s words or ideas as your own. Turning in AI writing as your own, when the assignment doesn’t allow it, is plagiarism too.

predictable

Easy to guess before it happens. AI writing is very predictable, because a chatbot picks likely next words. Simple, clear human writing is predictable too.

See Also: prediction

prediction

A best guess about something you don’t know yet. A prediction can be wrong.

Example:

A phone keyboard makes a prediction about your next word.

privacy

Your right to keep information about yourself to yourself, and to decide who gets to see it.

See Also: metadata, location data

product

The thing you make in a project, like a flyer, a study guide, or a plan.

prompt

What you type to tell an AI what you want. A good prompt has a task, context, and a format.

Example:

“I am in 10th grade. Give me 3 reasons dogs make good pets. Use simple words.”

See Also: task, context, format

prompt log

A list of every prompt you used in a project, and what you did with each answer.

See Also: prompt

random

With no pattern, so you can’t guess what comes next.

Example:

The middle of Rule 30 looks random.

recommendation

Something an app chooses for you, because it predicts you’ll click it or like it.

See Also: feed, prediction

regulation

A rule made by a government, like a law about how AI can be used.

responsible

Being the one who must answer for what happened, and fix it. When an AI makes a mistake, people argue about who is responsible.

reverse image search

Searching with a picture instead of words, to find where else the picture is online and where it first appeared.

See Also: lateral reading

revise

To change your work to make it better, often after feedback.

See Also: feedback, draft

rubric

A chart that shows how your work will be graded.

rule

An exact instruction that a computer follows: “If this happens, do that.” In a normal computer program, a person writes the rules.

Example:

An alarm clock follows one rule: “If the time is 7:00, ring.”

See Also: computer program, machine learning

scam

A trick to steal your money or your information. AI makes scam messages harder to spot, because it writes perfectly in any language.

See Also: warning sign, imposter

shortcut

A clue that gives the right answer in the training examples, but isn’t the real reason. Clever Hans the horse watched people’s faces instead of doing math. An AI learned to look for snow instead of wolves.

See Also: bias

skill

Something you can do well because you learned it and practiced it.

source

Where a fact comes from: a book, a website, a news story, or a person.

See Also: fact-check

stereotype

An idea that all people in a group are the same, like “all nurses are women.” AI can learn stereotypes from its training data.

See Also: bias

style

The way a picture looks: a photo, a cartoon, a watercolor painting, pixel art.

sycophancy

Agreeing with someone just to please them, even when they’re wrong. A chatbot can learn this, because people often give good ratings to answers that agree with them.

See Also: hallucination

synapse

The tiny gap between two neurons. Chemicals carry the signal across it. When you practice, the synapses you use get stronger.

See Also: neuron

task

One piece of work, like “write a report” or “fix a pipe.” A job is made of many tasks. In a prompt, the task is the job you want the AI to do.

See Also: prompt, automation

test data

New examples that an AI never saw during training. We use them to check what the AI really learned.

Example:

After training on cards T1 to T10, the class neuron was tested on cards X1 to X6, with no fixing.

See Also: training

threshold

The number that the total must be more than for a neuron to fire.

Example:

If the threshold is 4 and the total is 5, the neuron fires. If the total is 4, it doesn’t.

See Also: weight

token

A word or a piece of a word that a chatbot reads and writes. For example, “playing” might be two tokens: “play” and “ing.”

See Also: large language model

training

Showing an AI many examples so it can fix its weights. After each mistake, the weights change a little.

See Also: weight, test data

training data

All the examples an AI learned from: pictures, text, sounds, or numbers. An AI is only as good as its training data.

See Also: dataset, training

transfer learning

Starting from an AI that already learned something, then teaching it a new job with a few new examples. It’s much faster than starting from nothing.

Example:

Teachable Machine starts from a network that learned from millions of pictures. It only learns the last step from your pictures.

See Also: training

transformer

A kind of neural network, first shared by Google scientists in 2017. It uses attention to connect the words in a sentence. It’s the T in GPT.

See Also: attention, neural network, large language model

translate

To change words from one language to another, with the same meaning.

See Also: back translation

trolley problem

A famous thought experiment: a runaway trolley will hit 5 people. Would you pull a lever to send it toward 1 person instead? People still disagree about the answer.

See Also: ethics

Turing test

A game Alan Turing described in 1950. He called it the imitation game. A judge chats in writing with a person and a machine. If the judge can’t tell which one is the machine, the machine passes.

See Also: judge, chatbot

understand

To know what something means, not only what it looks like. Whether AI can understand is a question people still argue about.

Example:

In the Klingon Room, the person copies correct replies in Klingon, but they don’t understand Klingon.

See Also: ELIZA effect

verification code

A short number a website sends you, to prove it’s really you. Never share it with anyone.

See Also: scam

verify

To check that something is true, using good sources.

See Also: fact-check

voice clone

An AI copy of a person’s voice, made from a short recording. Scammers use voice clones to pretend to be someone’s family member.

See Also: deepfake

warning sign

A clue that something is wrong. Scam warning signs: hurry, fear, a prize, a secret, a strange way to pay, and a link or a code.

See Also: scam

watt-hour

An amount of electricity. A 10-watt light bulb that’s on for one hour uses 10 watt-hours. Charging a phone uses about 15 watt-hours.

weight

A number that says how much an input matters to a neuron. A big weight means the input matters a lot. A negative weight means the input makes the neuron less likely to fire. When a neural network learns, it changes its weights.

See Also: input, threshold, neural network
