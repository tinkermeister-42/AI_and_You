{\large\textbf{4. What did you see?}}

\vspace{0.5em}
In Run 2, the training score went up, but the test score did not. The network learned the training examples by heart. This is called \ansline{1.4in}{overfitting}.

\vspace{0.9em}
In Run 4, the network was not much better than guessing. Why? \ansline{2.9in}{The answer is not in the data.}

\vspace{0.9em}
An AI can only learn what is in its \ansline{1.0in}{data}.
