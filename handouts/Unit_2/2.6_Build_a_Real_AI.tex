{\large\textbf{5. What did you see?}}

\vspace{0.5em}
In Run 2a, the network had no hidden layer. It could only draw one \ansline{0.9in}{line}.

\vspace{0.9em}
In Run 2b, one hidden neuron fires only for \ansline{1.0in}{Giants}. The other fires for everything except \ansline{1.0in}{Minis}.

\vspace{0.9em}
In Run 3, the training score went up, but the test score went down. The network learned the training examples by heart. This is called \ansline{1.4in}{overfitting}.

\vspace{0.9em}
In Run 4, the network wasn't better than guessing. Why? \ansline{2.8in}{The home was picked at random. It isn't in the data.}

\vspace{0.9em}
An AI can only learn what is in its \ansline{1.0in}{data}.
