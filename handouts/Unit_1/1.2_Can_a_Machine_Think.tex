{\large\textbf{2. The imitation game}} (the Turing test)

\begin{center}\resizebox{0.68\linewidth}{!}{\fig{Unit_1/1.2_imitation_game}}\end{center}

\vspace{0.2em}
A \ansline{1.3in}{judge} asks questions. One player is a \ansline{1.2in}{person}, and one is a \ansline{1.2in}{machine}.

\vspace{0.9em}
The judge only reads \ansline{1.2in}{typed} answers. If the judge cannot tell, the machine \ansline{1.2in}{passes}.
